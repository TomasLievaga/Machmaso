# Machmaso collaboration rules

- The project name is Machmaso. Agamir and Tomas collaborate from separate computers.
- Communicate with Codex in English. Write code, comments, commit messages, and shared documentation in English.
- Inspect existing code and instructions before making changes.
- Keep changes focused on the requested task. Preserve unrelated work.
- Use a separate branch for each task. Integrate changes into `main` through pull requests, with review by the other collaborator.
- Never force-push shared branches or discard someone else's changes.
- Never commit credentials or real `.env` files. Use placeholder values in `.env.example` when needed.
- Run checks appropriate to the change. Report what was checked and any checks that could not be run.
- Keep setup instructions current when development commands change.
- The application stack and product requirements are not yet decided. The existing Python files are only a test scaffold; do not treat them as an architectural decision.
- Ask before adding paid services, deploying to production, or applying destructive database changes.
